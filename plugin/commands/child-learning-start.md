Start a local session for `$ARGUMENTS` (or ask the adult to choose/create a student). Creating a profile alone must generate no worksheet. Invite the adult to select structured capabilities they observe, complete the subject questionnaire, or explicitly choose a subject-entry diagnostic; free-text examples remain context only. Use `create_student` or `complete_student_intake` so the application places diagnostics near that reported level. Never record a parent statement or school placement as mastery. Load the actual local profile, full subject path, current placement, due reviews, and recent artifacts. Do not invent a student or tool result. Explain the next available action; do not mutate progress directly.
