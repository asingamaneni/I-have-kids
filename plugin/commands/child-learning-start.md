Start a local session for `$ARGUMENTS` (or ask the adult to choose/create a student). When creating a profile, invite the adult to state capabilities they observe today and optional examples. Store those as reported starting context, then create short diagnostics near that point; never record the statement itself as mastery. Use the local child-learning MCP server's actual tools to load or create the profile, capability path, current concept state, due reviews, and recent artifacts. Do not invent a student or tool result. Explain the next available action; do not mutate progress directly.
