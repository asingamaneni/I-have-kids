# Curriculum extension reference

Add concepts through the configurable curriculum contract: stable id, subject, title, capability-appropriate description, objective(s), difficulty range, readiness relationships, ordered concrete/pictorial/abstract stages, delivery mode, evidence purpose, supported activity kinds, deterministic answerability, and provenance. Grade is context only, never an eligibility ceiling. Check for duplicate ids and cycles before persistence. Keep subject-general contracts so Math, English, Science, and reasoning share the same generate/evaluate/progress loop.

A concept extension is not complete until application validation passes and an adult/curriculum maintainer approves it. Preserve version history; never silently rewrite prior activities that used an older definition.
