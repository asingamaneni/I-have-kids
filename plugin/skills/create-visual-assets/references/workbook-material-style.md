# Original workbook material style

Aim for calm, printable, picture-rich pages: one clear task, generous whitespace, large readable type, uncluttered line art, consistent object scale, and grayscale-safe distinctions. Images should teach the target concept, not merely decorate it. A picture-based item must say exactly what each image represents and must remain unambiguous when printed.

Create original wording, arrangements, characters, illustrations, and page structures. Do not copy third-party text, branding, logos, illustrations, answer keys, or protected worksheet layouts. Preserve provenance for any adult-approved local reference.
