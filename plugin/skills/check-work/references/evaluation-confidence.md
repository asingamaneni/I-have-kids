# Evaluation confidence reference

Use deterministic evaluation for known arithmetic, choices, matching, normalized text, sequence keys, score totals, thresholds, and schema checks. Use AI-assisted interpretation only when the code cannot prove the answer, and return item-level evidence, rationale, evaluator type, confidence, and an evidence status of confirmed, unconfirmed, or ambiguous.

A low-confidence or subjective observation is not a permanent learning fact. Preserve the original submission and evaluation, request adult review where it could affect progress, and write any correction as a new human override or corrected evaluation. Do not silently convert an image or handwriting guess into a score or progression event.
