# ADR 0002: Original workbook material system

## Status

Accepted.

## Decision

The worksheet system uses an original teaching rhythm: one skill focus, short directions, a concrete model or strategy, guided practice, independent practice, application, and review. Text, exercises, illustrations, page templates, and visual identity are created specifically for Learning Worktable.

No third-party workbook text, branding, proprietary illustrations, passages, questions, answer keys, or page compositions are reproduced.

## Consequences

- Worksheet templates are reusable contracts rather than static PDFs.
- Math, English, reasoning, and starter science share a predictable hierarchy.
- Visual regression, originality, and child-readability checks are part of the quality gate.
